# Rooster

Techno neon marketing site for Rooster. Frontend only.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- shadcn/ui (`src/components/ui`)

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The landing page plays `public/vid/hero-vid.mp4` full-screen. The coverflow in the bottom-right quarter links to Services, About, Packages, Projects, and Contact.
